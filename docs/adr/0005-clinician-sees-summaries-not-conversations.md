# The Clinician sees Summaries, not conversations

A Clinician sees a generated Summary, Signal trends and an Attention flag for each linked Patient. Raw audio and full transcripts are never shown to them. This keeps the Check-in a place where the Patient can speak freely, keeps the Clinician's workload low, and limits what Google's Limited Use policy treats as a human reading user data. Sharing requires the Patient's explicit Consent ([research](../research/calendar-and-health-apis.md)).

The Patient reads exactly the same Summary as the Clinician. The Attention flag is shown to the Clinician only, because seeing it could alarm the Patient.
